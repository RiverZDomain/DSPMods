# Blueprint Scaler Mod

A Dyson Sphere Program mod project exploring how planet-wide and polar blueprints can be adapted to different planet sizes.

The initial milestone is an installable BepInEx 5 plugin that adds a draggable floating scale window during blueprint placement. The value starts at 200 and is saved in the BepInEx configuration. Applying the selected scale to blueprint geometry is not implemented yet.

See [the package README](package/README.md) for Linux build and installation instructions. The existing [Idea](Idea) file sketches the planned blueprint-coordinate transformation.
